Before we clear context, please review our current conversation and save any notes worth keeping across sessions.

1. **Auto-memory files** — Update your memory files (in your auto-memory directory) with anything valuable from this session: key decisions, patterns discovered, issues resolved, user preferences observed, or architectural insights. Update existing entries rather than duplicating, and remove anything outdated.

2. **Project documentation** — Consider whether anything should be written to project docs (e.g. README, CLAUDE.md, or other docs in the working directory). For example: new conventions established, setup steps figured out, or decisions that future contributors should know about.

After saving, briefly summarize what you saved (or that there was nothing worth saving).

Then remind me to run `/clear` to clear the context.
